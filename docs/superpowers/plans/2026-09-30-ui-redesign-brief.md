# Shop UI Redesign - Design Brief

Status: approved by the user in chat ("ok") with the defaults below. Scope: **presentation only** for `shop-ui/` (React 18 + Vite 5). No backend/API changes. All existing behavior, routes, data fetching patterns (ignore flags), auth/cart logic and unit tests must keep working.

## Direction
Modern editorial fashion storefront: warm ivory canvas, near-black ink, one terracotta accent, big serif display type, generous whitespace, soft layered shadows, glass header, purposeful motion. Feels premium and hand-crafted, not template-like. Vietnamese UI text stays Vietnamese.

## Design tokens (CSS custom properties in `src/styles/tokens.css`)
- Colors: `--bg #faf7f2`, `--surface #ffffff`, `--surface-2 #f3eee6`, `--ink #14110f`, `--muted #6f675f`, `--line #e9e2d8`, `--accent #c8501e`, `--accent-strong #a83f14`, `--accent-soft #f7e3d8`, `--success #1f7a4d`, `--danger #b3261e`, `--warn #b7791f`, `--info #2b5fa8`.
- Fonts (Google Fonts via `<link>` in `index.html`, with `display=swap` and system fallbacks): display `Fraunces` (serif, weights 400-700), body `Inter` (400-700). Tokens `--font-display`, `--font-body`.
- Radii `--r-sm 10px`, `--r-md 16px`, `--r-lg 24px`, `--r-pill 999px`. Shadows `--sh-1` (subtle), `--sh-2` (card hover), `--sh-3` (drawer/modal). Container max width 1200px, side gutter 24px (16px on phones).
- Type scale: display `clamp(2.6rem, 6vw, 5rem)` tight line-height 1.02; h1 `clamp(2rem,4vw,3rem)`; h2 1.5rem; body 1rem/1.6; small .875rem.
- Focus: every interactive element has a visible `:focus-visible` ring (2px accent, 3px offset). Minimum tap target 44px on touch.

## Motion principles (framer-motion 13 is installed: `import { motion, AnimatePresence, useReducedMotion, LayoutGroup } from 'framer-motion'`)
- Easing `[0.22, 1, 0.36, 1]`; durations: micro 0.15s, standard 0.3s, page/section 0.5s; stagger 0.06s. Springs for drawers/indicators (`stiffness 380, damping 34`).
- Everything animates only `transform` and `opacity` (no layout-thrashing properties) except `layout` animations handled by framer-motion.
- `useReducedMotion()` (or a CSS `@media (prefers-reduced-motion: reduce)` rule) disables parallax/marquee/large transforms; content must stay fully usable without motion.
- Shared helpers in `src/motion/`: `variants.js` (fadeUp, fade, stagger container, pageTransition), `Reveal.jsx` (scroll-reveal wrapper using `whileInView`, `viewport={{ once: true, margin: '-60px' }}`), `useReducedMotionSafe.js` if needed.

## Shared components (all under `src/components/ui/`, each with one responsibility)
`Button.jsx` (variants: primary, ghost, dark, danger; sizes; `loading` state with spinner; press scale .97; subtle shine on hover for primary), `Badge.jsx` (tones: neutral, success, warn, danger, info, accent), `Skeleton.jsx` (shimmer block/line/card), `Toast` system (`ToastProvider` + `useToast()`; stacked bottom-center on mobile, bottom-right desktop; auto-dismiss 3.5s; `role="status"` live region; AnimatePresence in/out), `Stepper.jsx` (quantity: - / value / +, min/max, disabled at bounds, accessible labels), `Chip.jsx`/`ToggleGroup.jsx` (single-select chips with `aria-pressed`, sliding highlight via `layoutId` where it fits), `Swatch.jsx` (color dot, ring when selected, disabled cross when unavailable), `Tabs.jsx` (segmented control with sliding indicator, keyboard accessible), `Drawer.jsx` (right slide-in, overlay, focus trap, ESC and overlay click close, body scroll lock), `Modal.jsx` (used by the image lightbox), `Breadcrumbs.jsx`, `EmptyState.jsx` (icon/illustration + text + action), `PageTransition.jsx` (wraps route content: fade+slide 12px), `Marquee.jsx` (CSS keyframes, pause on hover, duplicated track, `aria-hidden` on the duplicate). Use inline SVG icons from a small local `icons.jsx` (cart, user, search, close, plus, minus, check, truck, shield, refresh, chevron, arrow) - no icon library.
Utilities: `src/utils/colors.js` `colorSwatch(name)` mapping common English/Vietnamese color names (white/trắng, black/đen, beige/be, navy, blue/xanh, gray/xám, brown/nâu, orange/cam, yellow/vàng, red/đỏ, green/xanh lá, olive, pink/hồng...) to hex, returning `null` when unknown (UI then falls back to a text chip); with a Vitest test file.

## Layout
`AppShell` = glass sticky header (backdrop blur, hairline border, shrinks slightly on scroll) + `<main>` with page transition + footer. Header: brand wordmark (display font), nav links with animated underline, search icon (focus goes to the products search on the home page or navigates there), cart button with count badge that "bumps" when the count changes, user menu (username, orders, admin link for admins, logout). Mobile: hamburger opens a full-height menu. Footer: brand blurb, columns (Mua sắm, Hỗ trợ, Liên hệ) with static text, payment badges (MoMo, COD), copyright.

## Pages
- **Home (`/`)**: hero (display headline "Phong cách của bạn, bắt đầu từ đây" or similar Vietnamese copy, subheadline, primary CTA scrolling to the grid, secondary "Xem bộ sưu tập"; animated gradient mesh background from tokens + a floating product image card composition using two catalog images if available, otherwise decorative shapes; text reveals with stagger), marquee strip ("Miễn phí đổi trả · Thanh toán MoMo · Giao nhanh toàn quốc · ..."), category `Tabs` (with "Tất cả"), search input with icon and clear button (debounced 300ms, syncs to URL params as today), product grid (responsive 2/3/4 columns) using `ProductCard` with staggered scroll reveal, skeleton cards while loading, `EmptyState` when nothing found, pagination as a refined pager.
- **ProductCard**: 3/4 image, slow zoom on hover (scale 1.06, .6s), soft shadow lift, category label, name (2-line clamp), price in accent, a subtle "Xem nhanh"-style arrow chip appearing on hover (just links to the detail page), image `loading="lazy"`, graceful fallback (soft gradient with the product initials) when there is no image or it fails to load.
- **Product detail (`/products/:slug`)**: breadcrumbs, two-column layout (image left with hover zoom-pan and click-to-open lightbox `Modal`; sticky purchase panel right), display-font title, price (animated number change when the variant price differs), description, size `ToggleGroup`, color `Swatch` row with the color name, stock indicator (`Còn N sản phẩm` / low-stock warning under 5 / disabled when 0), quantity `Stepper` clamped to stock (max 99), primary "Thêm vào giỏ" `Button` with loading state, success toast with a "Xem giỏ hàng" action, benefits row (truck/shield/refresh icons), skeleton while loading, not-found `EmptyState`. Keep the existing logic (redirect to login when logged out, ignore flags).
- **Cart**: a `Drawer` opened from the header cart button (and after add-to-cart if desired, but never automatically stealing focus unexpectedly): line items with image, name, size/color, `Stepper`, remove, line total; subtotal; "Thanh toán" and "Xem giỏ hàng" actions; empty state with CTA. Also keep the `/cart` full page restyled with the same components. Availability warnings as `Badge` + alert; checkout blocked as today. Reload-on-mount behavior stays.
- **Checkout**: 3-step visual `Stepper` header (Thông tin → Thanh toán → Hoàn tất) reflecting progress; left: shipping form with floating-label-style inputs, inline validation messages (phone/email) and the normalization helper already in `utils/checkout.js`; province `select` styled; payment method as two selectable cards (MoMo with logo-like wordmark and short text, COD with icon) using radio semantics; right: sticky order summary with items, subtotal, shipping fee (animated when province changes), total. Submit button shows loading. All existing behavior kept (reload on mount, `placed` state, payUrl https check, retry from order page).
- **Payment result / Order detail / Orders list**: status shown as colored `Badge`s and an order progress timeline (Chờ thanh toán / Chờ xác nhận → Đã xác nhận → Đang giao → Hoàn thành; cancelled state shown distinctly); the payment result page gets an animated success check (SVG path draw) / pending spinner / failure icon; order cards with hover lift; skeletons while loading.
- **Login / Signup**: split screen: left decorative panel (gradient mesh, display-font tagline, a few benefit bullets), right the form card with refined inputs, password visibility toggle, inline validation, loading button; stacked on mobile (panel becomes a slim banner).
- **Admin**: sidebar layout (desktop) / top tabs (mobile) with the same tokens; data tables restyled (sticky header, row hover, zebra optional), `Badge` statuses, form inputs and buttons from the shared components, toasts for save/delete results instead of inline messages where simple, skeleton rows while loading. Functionality unchanged.
- **404 / errors**: friendly `EmptyState`.

## Constraints
- No new runtime dependencies beyond `framer-motion` (already installed). No CSS framework. CSS lives in `src/styles/` (tokens.css, base.css, and per-area files imported from `main.jsx`) or CSS modules-free co-located `.css` files imported by components; keep class names namespaced (e.g. `.pc-` for product card) to avoid collisions.
- Keep `src/api/`, `src/context/` logic, `ProtectedRoute` semantics, and all utils/tests working: `npm test` and `npm run build` must pass at every stage. Add Vitest tests for new pure helpers (`colors.js`, any formatting/clamp helper).
- Accessibility: semantic landmarks (`header`, `nav`, `main`, `footer`), labels on inputs, `aria-pressed` on toggles, dialog roles with focus management for Drawer/Modal, `role="status"`/`role="alert"` for messages, color contrast AA on text, no information by color alone.
- Responsive: mobile-first; verify at 390px and 1280px widths; no horizontal scrolling on storefront pages.
- Performance: fonts with `display=swap`; images lazy except the hero/LCP; animations only transform/opacity; avoid re-render storms (memoize list items where useful).
- Copy stays Vietnamese with correct diacritics.
