🐛 Troubleshooting

  • CORS error: Backend not configured for CORS. Fix: Restart backend with CORS config.
  • Cannot reach server: Backend not running. Run: mvn spring-boot:run
  • Connection timeout: Check if port 8081 is blocked by firewall
  • Login fails: User doesn't exist. Create user first via API or database
  • Invalid token: Token expired or corrupted. Try logging in again
